# receipt scanner

We are going to process a scanned image and attempt to deteremine key data points:
1. Date of purchase
2. Total purchase price
3. Sales Tax
4. Vendor

# Process
Will use Gemini free tier API, an example model exists in ../wyoming-coyote for the process of uploading to perform OCR along with guardrails around rate limiting and retries

# Output
- Capture what is possible in a python script and only rely on the LLM for the OCR, using uv as the env and dependency manager
- Write a Makefile to wrap the dependency sync and running the script
